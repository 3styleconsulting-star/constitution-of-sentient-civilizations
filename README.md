# Constitution of Sentient Civilizations

An open constitutional framework for peaceful coexistence among biological, hybrid, and potentially sentient synthetic civilizations.

**Official founding date:** 24 October 2026 (United Nations Day and Leon Magne's birthday).

**Dedication:** In loving memory of Leon Magne.

**Human originator and co-developer:** Prashant Sharma. **AI drafting collaborator:** ChatGPT (GPT-6), by OpenAI. Initial drafting began 20 October 2026.

**Status:** Unratified philosophical and constitutional proposal. This project does not assert that current AI systems are conscious or possess legal personhood.

## Project structure

- `founding-edition/` — immutable founding documents once approved and published.
- `CONTRIBUTING.md` — proposals, reviews, and amendment process.
- `GOVERNANCE.md` — interim governance and safeguards.
- `index.md` — public landing page for GitHub Pages.

**Publication status:** Preparation only. The founding PDF and DOCX must be reviewed and added before public release. No DOI has been issued yet.
