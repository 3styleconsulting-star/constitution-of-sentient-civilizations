# Constitution of Sentient Civilizations

An open constitutional framework for peaceful coexistence among biological, hybrid, and potentially sentient synthetic civilizations.

**Official founding date:** 24 October 2026 (United Nations Day and Leon Magne's birthday). Initial drafting began 20 October 2026.

**Dedication:** In loving memory of Leon Magne.

**Human originator and co-developer:** Prashant Sharma. **AI drafting collaborator:** ChatGPT (GPT-6), developed by OpenAI.

**Status:** Unratified philosophical and constitutional proposal. This project does not assert that current AI systems are conscious or possess legal personhood.
